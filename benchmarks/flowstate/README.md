# FlowState — how much money can it absorb?

**Status: not started, and not released.** Work may not begin until the PI explicitly releases P2
at Checkpoint 2.3. This file is a placeholder so the three-project structure is visible; it is not
a plan, and nothing here has been designed.

P1 asked *is it real?* P2 asks *when does it break?* P3 asks the question a portfolio manager asks
first: **how much capital can this take before its own market impact eats the edge?**

## The known limitation, recorded now rather than discovered later

Capacity estimation ideally requires intraday volume profiles. If only daily bars are available,
the impact model is coarser than the research question deserves. Phase 3.0 opens with an honest
assessment of whether daily-bar impact estimation is defensible at all — with abandoning P3 among
the options put to the PI, not excluded from them.

Nothing else is written here on purpose.
