Run it yourself

Four commands, then this page is real.

Clone the repository and the console below stops being a picture. It runs against the same instruments the papers used — the same static auditor, the same point-in-time engine, the same Indian transaction costs. Nothing is uploaded, nothing is ranked, and no account is required.

The slow step is the price data. download_bhavcopy.py pulls years of NSE end-of-day archives and builds an 86 MB panel, so leave it running. It has not hung.

This is why the console is not hosted. It executes whatever Python you paste, in its own process, with no sandbox — acceptable only because the person pasting the code and the person running the server are the same person. The socket is pinned to loopback and there is no flag to change it. On the open internet that is remote code execution, which is a thing to build properly or not at all.

bash — local console
# clone and install — Python 3.11 or newer
git clone https://github.com/Ashwin-aadi/Trivijaya-Quant-Research.git
cd Trivijaya-Quant-Research
bash env/setup.sh
source .venv/bin/activate       # .venv/Scripts/activate on Windows

# build the price data — raw archives first, then derived from them
python scripts/download_bhavcopy.py    # years of NSE end-of-day. Slow.
python scripts/build_universe.py
python scripts/build_corporate_actions.py

# open http://127.0.0.1:8000
python webui/server.py

Result

Results appear here. On a real run the audit is instant and the backtest takes about half a minute for 1,232 sessions. Press a button to see what this copy of the page can and cannot do.

Why your Sharpe falls as you iterate

Every strategy you evaluate in a session counts as a trial, and the deflated Sharpe adjusts for how many things you tried. Submit forty variants and keep the best, and the best one now has to clear a higher bar — because with forty tries, something looks good by luck alone.

The counter is per-session and lives in memory. It never touches the repository's tamper-evident ledger, which belongs to the published results.

A high deflated Sharpe here is weak evidence

The correction deflates by how many things you tried and by how much they differed. Two near-identical variants have almost no spread between them, so there is almost nothing to deflate and the number comes back near 1.000 — which reflects a search too small to have found anything by luck, not a strategy that works.

The published results deflate against 1,887 genuinely distinct trials. A session of five does not compare.

Passing the auditor is not a verdict on the strategy

The static layer reads the code for patterns that see the future. It catches all three deliberately leaky fixtures in the repository and flags none of the thirty honest ones, but it returns a zero on one leak class that the corpus almost certainly contains — a detector gap that is reported rather than quoted as a clean result.

The engine is the second line: any signal timestamped later than the data it could have seen raises PointInTimeError rather than quietly producing a good number.
