Quant Research

This lab builds instruments that detect when a quantitative result is false.

Almost every trading signal that looks profitable on historical data is not — the causes are leakage, where the code sees the future, and multiple testing, where enough attempts make luck look like skill. The programme exists to destroy attractive-looking findings. A negative result is a successful outcome here.

The headline figure

The metric this was built to produce, returning a null.

An auditor earns its place by knowing when to abstain — by the strategies it keeps performing better, out of sample, than the ones it discards. Every combination of the three layers was measured against random rejection at matched coverage. None beat it.

The method

Three questions, asked in order.

Each stage answers the question the previous one raises. A signal that survives one stage is not thereby true; it has only earned the next question.

Start A signal that looks profitable on historical data.

Stage 01

Is the signal real?

AlphaAudit

Three independent layers: static analysis of the code for lookahead, deflation of the Sharpe ratio against an honest trial count, and a language model reading the stated rationale against what the code does. Most signals are eliminated here.

This raisesSuppose it is real. When does it stop working?
→
Stage 02

When does it break?

RegimeStress

History offers one pandemic and one rate cycle, which is not much evidence. Market conditions are labelled by regime, then histories that never happened are generated by block-bootstrapping real ones, and the strategy is re-run against each.

This raisesSuppose it survives. How much capital can it carry?
→
Stage 03

How much money can it absorb?

FlowState

Deployment capacity measured from observed liquidity: the largest book at which the strategy can still trade inside its own participation limit. A constraint, computed from real turnover — never an estimate of where the edge erodes.

Terminates inA capacity figure — or a negative result, which is the more common outcome.

Result An instrument survives all three questions, or it does not. Either answer is a finding.

Benchmarks

Three instruments.
All released and frozen.

Frozen means the specification will not change, so results stay comparable across time and across strategies. Each is reproducible from raw data by a documented command sequence, and each carries a corrections log recording every defect found after freezing and exactly what it changed.

01
AlphaAudit
Released · Frozen v1.2

The question

Is the signal real, or an artefact of leakage and multiple testing?

A local model generated 1,550 strategies. Each was read for lookahead, deflated against a tamper-evident count of every trial attempted — failures included — and checked for whether its stated reasoning matched its code.

Headline finding

0 of 631 backtested strategies cleared a deflated-Sharpe probability of 0.95. The highest in the corpus was 4.37 × 10⁻⁸.

Also measured · 40.7% of draws executed at all · 14.5% executed and took a position · 14.3% carried a static leakage finding · 15.6% of profitable strategies reversed sign under Indian statutory costs

02
RegimeStress
Released · Frozen v1

The question

Under which market conditions does the edge disappear?

Regimes are labelled causally, on an expanding window, so the labels never see the future. Counterfactual histories are then resampled in blocks that preserve volatility clustering, and fragility is measured as the spread of performance across them.

Headline finding

Fragility is generator-independent: a median of 0.618 locally against 0.566, 0.624 and 0.696 for three frontier models. It is closer to a property of the market than of the author.

Also measured · fragility is not predictable from strategy characteristics, best out-of-sample R² +0.024 · 27 of 174 audit survivors were not deterministic functions of their own inputs, disclosed rather than quietly dropped

03
FlowState
Released · Frozen v1

The question

How large a book can the strategy trade within its own participation limit?

Capacity is computed from observed traded value and the participation constraint, assuming no impact coefficient. The benchmark also carries a first-class negative result: why daily bars cannot price transient market impact at all.

Headline finding

Binding capacity of ₹0.81–7.91 crore across five standard factors — roughly one to ten million US dollars, set by the least-liquid position.

Also measured · capacity from a typical session overstates the binding figure by 4.3× to 26.2× · deployable size does not collapse when foreign flows reverse, ratios 0.94–1.24 · no factor's edge decays measurably from 1 to 63 sessions

The cross-cutting result

Better code is not better evidence.

The obvious objection to all of the above is that it describes one small local model rather than machine-written strategies in general. It is the right objection. At the front of the funnel

The difference is total.

All 60 of 60 frontier candidates executed to completion and took a position, against the local model's 14.6%. The execution barrier that dominates the local corpus is an artefact of model capability, and it disappears when capability rises.

100% versus 14.6% · n = 60 and n = 830

At the back of the funnel

There is no difference at all.

Not one of the sixty attained a deflated-Sharpe probability above 0.95 at its own honest trial count, on development or on holdout. The median holdout Sharpe is worse for every frontier arm than for the local reference.

0 of 60 cleared · 11 of 60 reversed sign under costs

This is a separation, not a ranking. Frontier models solved the problem the code-generation literature measures. They did not touch the problem this framework measures.

 The auditor null survived two corrections to the pipeline — a defective cost implementation, rebuilt, and a sign error inverting the auditor's confidence ordering. Both were repaired, the holdout was reopened once for each under written prior authorisation, and the null was recomputed. The magnitudes moved; the conclusion did not. The diffs that produced each correction are published, because we re-ran it and the conclusion held is what a researcher would say in both the honest and the dishonest case.

The population being ranked is one in which 14.5% of draws trade at all and nothing clears deflation. Asking an auditor to rank that population may be asking it to order noise. The frontier arms narrow the confound — stronger generator, 100% execution, same null — but twenty candidates per arm does not eliminate it.

Compute-matched comparison

A five-call agent that beats one prompt has proved nothing.

A scaffolded generation method spends several times the tokens of a single call. The honest control is therefore not plain prompting at its natural budget — it is plain prompting run k times at the scaffold's budget, allowed to keep its best. Under that control, every scaffold loses.

How the numbers are kept honest

The apparatus that makes the results checkable.

Every one of these is a constraint the repository enforces mechanically rather than a promise made in prose. They exist because the failure modes this lab studies are the ones a careful researcher still commits by accident.

01

Point-in-time enforced by the engine

Every signal carries the timestamp at which its information became available. If an order's signal timestamp is not strictly prior to its fill, the engine raises PointInTimeError — an exception, not a warning. Lookahead is made hard to express rather than forbidden by convention.

02

A survivorship-free universe

The universe on any date holds exactly the index constituents of that date, including names later delisted or removed. A universe built from today's constituents applied backwards would invalidate everything downstream, and no amount of care elsewhere would recover it.

03

A tamper-evident trial ledger

Every evaluation increments an append-only, hash-chained counter — including syntax errors and crashes, which consumed search effort too. The generator cannot write to it. Deflation is only as honest as its denominator, and 3,499 trials are recorded.

04

Purged cross-validation with embargo

Overlapping label windows are purged from training folds and an embargo follows each test fold, so serial correlation cannot leak a result across the boundary. Any fitted transform is fit on training data alone.

05

No number is typed twice

Every figure in every paper is a macro emitted by a build script from a named artefact. A checker fails the build if a bare numeral appears where a claim belongs. Transcription error is removed as a category rather than guarded against.

06

A holdout that is spent, not consulted

The 2025 panel is evaluated only under written prior authorisation, and every access is logged with its reason. After an evaluation, no further tuning of anything occurs. Where it was reopened — twice, for two pipeline defects — the diffs are published.

07

Costs that Indian backtests usually omit

Securities transaction tax, exchange charges, SEBI turnover fees, GST, stamp duty and brokerage, per leg and per segment, with participation-scaled slippage. Not a flat basis-point haircut. It reverses the sign of 15.6% of the profitable strategies.

08

Reproducible from raw, at zero cost

Global seed 42, a run manifest per execution carrying git SHA, package versions, model tags and input hashes. All inference is local. The market-data budget is ₹0, and no source requiring an account or KYC is used.

Run it yourself

The repository is public.

Clone it and run a local console that audits and backtests your own strategy against the same instruments used here — the same static auditor, the same point-in-time engine, the same Indian transaction costs. Nothing is uploaded, nothing is ranked, and no account is required.

This page computes nothing. Every result above is produced by code you run yourself, against data you build yourself.

See the console ↗ Repository ↗

The console is deliberately not hosted anywhere. It executes whatever Python you paste, in its own process, with no sandbox — which is acceptable only because the person pasting the code and the person running the server are the same person. Its socket is pinned to loopback and there is no flag to change it. Putting it on the open internet would be remote code execution, and that is a thing to build properly or not at all.

bash — local console
# clone and install — Python 3.11 or newer
git clone https://github.com/Ashwin-aadi/Trivijaya-Quant-Research.git
cd Trivijaya-Quant-Research
bash env/setup.sh
source .venv/bin/activate       # .venv/Scripts/activate on Windows

# build the price data — raw archives first, then derived from them
python scripts/download_bhavcopy.py    # years of NSE end-of-day. Slow.
python scripts/build_universe.py
python scripts/build_corporate_actions.py

# open http://127.0.0.1:8000
python webui/server.py
