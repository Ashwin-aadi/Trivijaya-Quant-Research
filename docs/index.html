Measurement infrastructure · Indian equities

Instruments that detect when a quantitative result is false.

Almost every trading signal that looks profitable on historical data is not. The two dominant causes are leakage — the code sees the future — and multiple testing — try enough things and something looks brilliant by luck. This is the apparatus that separates real findings from artifacts, applied to a market where it does not currently exist openly.

FlowState

How much money can it absorb?

Deployment capacity measured from observed liquidity rather than an assumed impact coefficient — and a first-class negative result showing why daily bars cannot price market impact at all.

₹0.81–7.91 crbinding capacity across five standard factors: roughly one to ten million US dollars, set by the least-liquid position.

A negative result is a successful outcome here. This machinery exists to destroy attractive-looking findings. “The signal did not survive” is the honest majority case, and every benchmark is built to report it rather than to avoid it. That is what separates a research result from a backtest.

Run your own strategy through it

The repository ships a local console: paste a strategy, get the leakage findings and a point-in-time backtest over 1,232 sessions of Indian equities, net of statutory costs.

# clone and set up
git clone https://github.com/Ashwin-aadi/Trivijaya-Quant-Research.git
cd Trivijaya-Quant-Research
pip install -r env/requirements.txt

# build the price data (immutable raw, then derived)
python scripts/download_bhavcopy.py
python scripts/build_universe.py
python scripts/build_corporate_actions.py

# open http://127.0.0.1:8000
python webui/server.py
  • The same static auditor the papers used, imported frozen.
  • The same backtest engine, with point-in-time discipline enforced by the engine rather than trusted to the author.
  • Indian transaction costs in full: STT, exchange charges, SEBI fees, GST, stamp duty, plus a volume-participation slippage model.
  • A session trial counter, so your deflated Sharpe gets harder to clear the more variants you try.
  • Runs entirely on your machine. Nothing is uploaded, nothing is ranked, no account.
This page cannot run anything. It is static, so there is no auditor and no backtester behind it — a page that pretended otherwise would be showing you numbers it did not compute. The console is real code and runs locally, on your clone, under your own account.
