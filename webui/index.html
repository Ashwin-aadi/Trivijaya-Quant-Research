Result

Results appear here, stage by stage as each finishes, and spread across the page rather than stacked in one column. The static layer is instant; the local 7B takes a few seconds; the backtest runs 1,232 sessions and takes about half a minute, after which the deflation, fragility, capacity and the book measures all come from that same run.

Why your Sharpe falls as you iterate

Every strategy you evaluate in this session counts as a trial, and the deflated Sharpe adjusts for how many things you tried. Submit forty variants and keep the best, and the best one now has to clear a higher bar — because with forty tries, something looks good by luck alone.

The counter is per-session and lives in memory. It never touches the repository's tamper-evident ledger, which belongs to the published results.

A high deflated Sharpe here is weak evidence

The correction deflates by how many things you tried and by how much they differed. Two near-identical variants have almost no spread between them, so there is almost nothing to deflate and the number comes back near 1.000 — which reflects a search too small to have found anything by luck, not a strategy that works.

The published results deflate against 1,887 genuinely distinct trials. A session of five does not compare.

Passing the auditor is not a verdict on the strategy

The static layer reads the code for patterns that see the future. It catches all three deliberately leaky fixtures in the repository and flags none of the thirty honest ones, but it returns a zero on one leak class that the corpus almost certainly contains — a detector gap that is reported rather than quoted as a clean result.

The engine is the second line: any signal timestamped later than the data it could have seen raises PointInTimeError rather than quietly producing a good number.

This console is not hosted anywhere, and should not be. It executes whatever Python is pasted into it, in its own process, with no sandbox — acceptable only because whoever is pasting the code and whoever is running the server are the same person.
